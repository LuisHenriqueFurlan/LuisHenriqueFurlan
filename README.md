### About Me

I am a Software Engineering student focused on backend development and API design. My work centers on building well-structured, maintainable services with Node.js, and I am currently deepening my understanding of SOLID principles and Clean Code to write software that scales well and is easier to reason about over time. Alongside my studies, I build real-world portfolio projects that range from authentication APIs to marketplace and management platforms, applying what I learn in practical, production-style scenarios. I approach software development as a continuous learning process, staying up to date with best practices across the Node.js ecosystem and related tools.
